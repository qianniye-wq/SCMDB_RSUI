# SCMDB_RSUI
Localization for scmdb
由RSUI汉化组制作的SCMDB中文本地化
本项目立项于2026年4月2日晚
This project was approved on the evening of April 2, 2026.

## 用法
# 自动
# 直接访问 https://scmdb.net/?lang=https://raw.githubusercontent.com/acewinner1999/SCMDB_RSUI/refs/heads/main/lang-cn-rsui.json
# 手动
# 访问 https://scmdb.net 官网 点击网站右上方的地球图标，在输入框内输入https://raw.githubusercontent.com/acewinner1999/SCMDB_RSUI/refs/heads/main/lang-cn-rsui.json后按下回车即可

## USAGE
# AUTO
# Direct access https://scmdb.net/?lang=https://raw.githubusercontent.com/acewinner1999/SCMDB_RSUI/refs/heads/main/lang-cn-rsui.json
# Manual
# Visit https://scmdb.net/ and click the globe icon in the upper right corner. Then enter https://raw.githubusercontent.com/acewinner1999/SCMDB_RSUI/refs/heads/main/lang-cn-rsui.json and press Enter.
